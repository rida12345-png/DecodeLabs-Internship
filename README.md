# 🤖 Rule-Based AI Chatbot

## 📌 Description

Rule-Based AI Chatbot is a Python project developed during my DecodeLabs AI Internship. The chatbot interacts with users using predefined rules and keyword matching to provide helpful and engaging responses.

---

 ✨ Features

- 👋 Responds to greetings
- 🎬 Recommends movies
- 🎵 Suggests songs
- 📚 Recommends books
- 🍕 Suggests food
- 🏔️ Recommends travel destinations
- 😂 Tells programming jokes
- 💡 Shares motivational quotes
- 🤖 Provides basic information about Artificial Intelligence
- 🐍 Answers basic Python-related questions
- 🚪 Supports exit commands such as **bye**, **exit**, **quit**, and **goodbye**

---

## 🛠️ Technologies Used

- Python
- Rule-Based Logic
- Conditional Statements (if-elif-else)
- Functions
- Loops
- String Handling
